개인정보처리방침

시행일: 2026년 10월 22일

1. 개요

history-autotube(이하 "본 프로그램")는 한 명의 운영자가 직접 운영하는 유튜브 채널들(역사·성경·불교 이야기)에만 사용하는 개인용 영상 제작·업로드 도구입니다. 본 방침은 본 프로그램이 Google 계정 및 YouTube API를 통해 접근하는 정보와 그 처리 방식을 설명합니다.

2. 접근하는 정보와 목적

  • YouTube 업로드·관리 권한 (youtube.upload, youtube): 운영자 본인의 채널들에 영상을 업로드하고, 제목·설명·썸네일·공개 예약을 설정하기 위해 사용합니다.
  • YouTube 분석 보기 권한 (yt-analytics.readonly): 운영자 본인 채널들 영상의 조회수, 시청 시간, 썸네일 클릭률을 확인해 다음 영상 기획과 썸네일 선택에 참고하기 위해 사용합니다.

본 프로그램은 다른 사람의 Google 계정, 채널, 개인정보에 접근하지 않으며, 시청자 개인을 식별하는 정보를 수집하지 않습니다.

3. 보관

Google이 발급한 인증 토큰은 운영자의 개인 컴퓨터에만 저장되며 외부 서버로 전송되지 않습니다. 채널 통계는 영상 기획 목적으로만 운영자의 컴퓨터에서 처리됩니다.

4. 제3자 제공

본 프로그램은 Google 사용자 데이터를 판매하거나 제3자에게 제공하지 않으며, 광고 목적으로 사용하지 않습니다. 본 프로그램의 Google API 사용은 Google API 서비스 사용자 데이터 정책 (제한적 사용 요건 포함)을 준수합니다.

5. 권한 철회와 삭제

Google 계정의 타사 앱 액세스 관리 페이지에서 언제든지 본 프로그램의 접근 권한을 철회할 수 있습니다. 권한을 철회하면 운영자 컴퓨터에 저장된 토큰은 더 이상 사용할 수 없으며, 운영자는 해당 토큰 파일을 삭제합니다.

6. YouTube 서비스 약관

본 프로그램은 YouTube API 서비스를 사용합니다. 사용 시 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.
