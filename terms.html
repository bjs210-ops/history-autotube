1. 서비스 내용

history-autotube는 한 명의 운영자가 직접 운영하는 유튜브 채널들(역사·성경·불교 이야기)의 영상 제작·업로드·통계 확인을 위해 사용하는 개인용 프로그램입니다. 외부 사용자에게 제공되지 않습니다.

2. 이용 조건

본 프로그램은 YouTube 서비스 약관과 YouTube API 서비스 약관을 준수하는 범위에서만 사용됩니다.

3. 콘텐츠

제작되는 영상은 공개된 역사·경전·학술 자료를 바탕으로 하며, 사실 확인 절차를 거칩니다. 사용된 공개 라이선스 이미지의 출처는 각 영상 설명란에 표기합니다. AI로 생성한 음성·이미지·음악이 포함될 수 있으며, 이는 영상에 표시합니다.

4. 책임의 한계

본 프로그램은 있는 그대로 제공되며, 운영자 본인의 채널 운영 외의 목적으로 사용되지 않습니다.
